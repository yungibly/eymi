## Built for everyday documents

Keep the details in [project notes](./notes.md).
A file stays a file — wherever you open it.

Use **strong words**, *a little emphasis*, and `inline code` when they help.
The writing column stays comfortable as the window grows. Long prose wraps
at words while selections and edits still refer to the original Markdown.
